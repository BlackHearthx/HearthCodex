# Changelog

## 1.0.0

- First public release as **HearthCodex**.
- Added a progressive bestiary opened with **B** by default.
- Added observation discovery, Vegvisir boss discovery, and credited-kill study progress.
- Added biome and knowledge filters, search, localized creature data, drops, weak spots, and resistances.
- Added weapon recommendations based on known recipes, creature modifiers, and varied weapon families.
- Added trophy-first creature portraits with a safe rendered fallback.
- Added per-character persistence and multiplayer kill-credit support.
- Added English, Brazilian Portuguese, and European Portuguese localization.
- Preserved progress created during Creature Codex development builds.

## Development history

- Built biome evidence from world spawns, fixed locations, dungeon rooms, trigger spawners, spawn areas, and boss altars.
- Added compatibility guards for malformed or incomplete modded content.
- Added bounded portrait caching and isolated catalogue source failures.
